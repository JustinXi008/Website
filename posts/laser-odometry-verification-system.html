Laser Odometry Verification

A background odometry plug-in that uses distance sensors to check and correct a robot’s position automatically.

April 5, 2026 Completed

What I built

I built Laser Odometry Verification (LOV), an odometry plug-in that provides continuous, automatic, distance-based resets for a robot’s positioning system. It runs in the background, uses distance sensors to calculate the robot’s position, and synchronizes that information with the main position-tracking object.

Why I built it

Positioning systems often rely on a single manual reset or require separate code for periodic sensor checks. LOV supports manual resets, but its main purpose is to automate the process continuously so position corrections can happen without interrupting the rest of the robot’s control system.

Accuracy and control

I added automatic sensor-value accumulation to improve accuracy while the robot is stationary. Customizable minDelta and maxDelta filters account for normal sensor variation and obstacles on the field, while a maxSyncPerSec controller limits how often the system synchronizes its position.
